# 分类方案专区

这里是社区分享的分类方案集合。**不用手动改文件**——打开面板
（`打开面板.bat`）→ 右上角「⚙ 工具」→「分类方案专区」，
本目录下的所有方案会自动列出来，点开预览、一键导入。

## 导入行为（重要）

- **增量合并，不是覆盖**：只新增你还没有的规则；和你的自配冲突的条目会
  列出来跳过，你的 `category.txt` 永远不会被整个换掉
- 导入前有预览清单：**将新增 N 条 / 冲突跳过 M 条**，还带 PII 检查
  （方案里若含手机号/邮箱会直接标红拒导）
- 导入后立即生效，随时可在「分类管理」里再调整

也支持手动方式：把方案文件内容**追加**到 `专注记录\category.txt` 末尾
（同名分类出现多次会自动合并规则；`#专注#` 标记取或）。

## 规则格式速查

```text
#注释行
#专注#办公|proc=Code.exe,proc=WINWORD.EXE     ← 带专注标记
视频|proc=mplayerc.exe,title=*bilibili*       ← proc= 按进程名（支持 * 通配）
游戏|title=*原神*                              ← title= 按窗口标题关键词
```

- 同一分类名可写多行/多次出现，规则会合并；**顺序 = 匹配优先级**
- 通配符：`*` 任意串、`?` 单字符（不带 `*` 时 proc 精确匹配、title 子串匹配）

## 提交你的方案

1. 复制你的 `专注记录\category.txt`，**先删掉私人条目**（你的姓名、
   只属于你的 title 关键词等）——面板导入时的 PII 检查也会帮你把关
2. 放到本目录：`分类方案/你的昵称-方案名.txt`（可以放多个方案文件）
3. 提交 Pull Request 或开 Issue 粘贴内容
