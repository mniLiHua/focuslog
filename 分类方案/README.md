# 分类方案专区

这里是社区分享的 `category.txt` 分类方案集合。挑一份喜欢的，覆盖你的
`专注记录\category.txt` 后重开面板即可生效（你的记录数据不受影响）。

## 提交你的方案

1. 复制你的 `专注记录\category.txt`，**先删掉私人条目**（你的姓名、
   只属于你的 title 关键词等）
2. 放到本目录：`分类方案/你的昵称-方案名.txt`
3. 提交 Pull Request 或开 Issue 粘贴内容
