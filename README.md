# 焦点监控 FocusLog
> **作者：冰叁狼** · 纯本地、零依赖、数据不上网


自动记录 Windows 电脑的窗口使用时长，按分类统计专注时间。
一个自己用的轻量级「时间去哪了」工具：后台静默采样前台窗口，按你自定义的规则归类，
实时算出今天真正专注了多久。**数据全部存在本地 txt，不联网、不上传。**

当前版本：见 `VERSION.txt`（发版以 git tag 为准，如 `v2.11.0`）

## 功能

- 每 10 秒采样一次前台窗口，记录进程名与窗口标题
- 按 `专注记录\category.txt` 的规则归类，行首加 `#专注#` 即算专注时长
- 后台静默运行（无控制台窗口、无托盘图标）
- 键鼠 5 分钟无输入自动暂停（键盘输入也算活跃）；视频/电影窗口延长到 45 分钟
- 锁屏 / 休眠自动暂停：锁屏那一刻即停表，解锁立刻恢复
- 专注时长达到 1h / 3h / 5h 弹系统通知
- 实时生成「专注 Xh_在线 Yh.txt」，桌面上扫一眼就知道今天状态
- **时间面板**：单文件 HTML 看板（零依赖、离线可用），白天 / 夜晚双主题；
  范围四档（今日 / 近 7 天 / 近 30 天 / 全部）+ 粒度三档（按天 / 按周 / 按月），
  趋势图 x 轴带日期与周几小字，点任意一格看那一格的明细
- **面板服务**：本地小服务（只绑 `127.0.0.1`），数据每 60 秒自动刷新；
  「⚙ 工具」里三个页签 ——「分类助手」（搜索 / 排序 / 批量改分类）、
  「分类管理」（改名 / 切专注 / 增删规则 / 删分类，写回自动备份 .bak）、
  「导入旧数据」（自动搜索旧项目并一键导入）
- **目标与提醒**：`专注记录/goals.json` 里设每日专注目标与单应用上限，达标/超限弹提醒
- **周报**：每周一自动生成 `docs/周报/YYYY-Www.md`（七天明细 + 与上周对比 + 分类/应用 TOP）
- **活跃时段热力图**、**分类近 30 天趋势**、**CSV 导出**

## 全自动的部分（不用你管）

每天第一次跨过零点时，守护程序会自动跑一遍：

1. **归档** —— 把本月之前的数据按月收进 `归档\YYYY-MM\`（补齐式，漏跑也能补）
2. **重算深耕记录** —— 按当前 `#专注#` 规则重算（默认只算未归档月份）
3. **导出统计** —— 更新 `时长统计\`

三步都幂等，日志里会留一行 `[MAINTAIN]`（失败则留 `[MAINTAIN-FAIL]|异常信息`，不静默）。

触发点有**两条**，都会跑：① 进程一直开着、跨过零点；② **开机自启**——
昨天关机、今早启动（这是最常见的情况，v2.11.1 前漏的正是这条）。

面板「⚙ 工具」里只保留**分类助手**（必须人判）+ 一个手动兜底的「立即维护」。

## 快速上手

1. 双击 `开始记录.bat`（开始记录 + 设开机自启）
2. 双击 `专注记录\面板（服务）.bat` —— 浏览器打开面板，右上角「⚙ 工具」
3. 在面板里跑一次「扫描未分类进程」，把没归类的进程归进去
4. 想开机就记录：双击 `焦点监控\开机自启.bat`

## 日志格式

```
19:31:45|WorkBuddy.exe|WorkBuddy
19:31:55|.
19:32:05|.
19:32:15|chrome.exe|GitHub - 你的仓库
19:32:25|[LOCK]|锁屏暂停
19:40:02|[UNLOCK]|解锁恢复
19:40:02|chrome.exe|GitHub - 你的仓库
```

- **完整行** `HH:MM:SS|进程名|窗口标题`
- **省略行** `HH:MM:SS|.` —— 点压缩，表示「还是上一个窗口」，体积降约 85%
- **标记行** `[PAUSE]` / `[RESUME]` / `[LOCK]` / `[UNLOCK]` / `[MAINTAIN]` —— 不计时长
- 命中小抄表（密码管理器、聊天软件、含「密码/银行/验证码」等词的标题）的条目，
  标题一律写成 `[已脱敏]`

## 兼容性：老记录还能不能用？

能。跑 `python tests\selftest.py`（14 项断言）会验证：

| 老格式 | 支持 |
|---|---|
| v2.5 完整行日志（无点压缩，归档里 2026-05 就是这种） | ✅ |
| v2.6 点压缩 `HH:MM:SS|.` | ✅（还能还原出进程名） |
| v2.7 `[LOCK]` / `[UNLOCK]` | ✅ 中断段不计入在线 |
| v2.7.2 `[PAUSE]` / `[RESUME]（暂停 X）` | ✅ 暂停时长不计入在线 |
| 混排 / 空文件 / 只有标记行 | ✅ 不崩、返回空 |
| 旧版 `category.txt`（没有游戏/音乐分类） | ✅ 照常解析，专注标记照旧 |
| 真实归档日志抽样 | ✅ |

一句话：**新版本只会往日志里加新标记，不改老行的含义**，所以老日志不用迁移。

## 分发给朋友 / 更新

```bat
打包发布.bat          :: 生成 _release\FocusLog_vX.Y.Z.zip（21 MB，含 exe，不含任何数据）
```

- 包里只有程序 + 文档 + 空数据骨架；`category.txt` 会先清掉私人条目
  （见 `工具\make_release.py` 的 `PRIVATE_RULES`，发版前扫一眼）
- 打完用 `gh release create v2.9.1 _release\FocusLog_v2.9.1.zip --title "FocusLog v2.9.1" --notes-file docs/CHANGELOG.md`，
  再补一份固定名 `FocusLog_latest.zip` 供 `更新.bat` 使用
- ⚠️ **仓库是私有的**：朋友直接下载 Release 需要授权。三选一：
  ① 把仓库改成 public；② 让朋友装 `gh` 并 `gh auth login`；③ 直接把 zip 发给他

朋友那边更新：双击 `更新.bat` —— 只替换 `.py/.bat/.exe/docs`，
**`category.txt` 和所有日志都不动**，旧程序自动备份到 `_backup_时间戳\`。

## 技术说明

- Python 编写，已打包为独立 exe，**无需安装 Python 或依赖**
- 支持 Windows 10/11 64 位
- 开机自启走注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
- 打包：`build.bat`（`--noconsole` 给守护程序，`--console` 给统计/面板）
  ⚠️ 跨目录模块（`category_utils` / `archive_utils` / `summary` / `chart_templates`）
  必须显式 `--paths` + `--hidden-import`，否则打包出来的 exe 会
  `ModuleNotFoundError`
- ⚠️ `*.bat` 必须存 **GBK**（cmd 按代码页读文件；UTF-8 的中文会变乱码，
  连 `start "" "面板.html"` 这种路径都会找不到）
- ⚠️ onefile exe 下 `__file__` 指向 `%TEMP%\_MEIxxx`，不能拿来当数据目录
  （代码里用 `sys.frozen` 判断，以 exe 自身位置为准）
- ⚠️ PowerShell 脚本里**别写中文**：`powershell.exe` 按系统 ANSI 读 `.ps1`，
  UTF-8 的中文会被解成乱码（连 `Set-Location E:\桌面\...` 都会找不到路径）。
  需要中文输出的脚本请用 Python 写，或把 .ps1 存成 GBK。
