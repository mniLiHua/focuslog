# 开发纪律（每次改动前过一遍）

> 2026-10-09 固化。目的：不依赖临场记性——该叫谁、怎么发版、哪些坑，全在这里。

## 0. 专家召唤（每次任务的第一步，铁律）

1. 回复**首行**固定输出：`专家：X（因为 Y）`
2. 按下表命中即召唤；一个任务可多专家协同
3. 收工时把**新出现的触发情境补进本表**（自固化）

| 触发情境 | 召唤 | 理由 / 本项目已知约束 |
|---|---|---|
| 本地服务路由 / 接口 404 500 / 新增 API | `code-reviewer` | GET/POST 共用入口只判命中，**404 兜底必须留在各入口末尾**（曾致首页永远 404） |
| 面板 UI / 卡片 / 图表 / 弹窗体验 | `viz-designer` | 零依赖单文件 HTML；数据内联；双主题 `#1a1a2e/#22223a/#66BB6A` |
| README / CHANGELOG / 使用说明 / Release 说明 | `technical-writer` | 单一来源，版本表述以 CHANGELOG 为准 |
| 打包 / 发版 / 更新器 / Release 自动化 | `devops-automator` | 用 `工具\发版.py`，别在临时目录拼脚本 |
| 接口慢 / 打开慢 / "加个缓存行不行" | `perf-benchmarker` | **先量基线再改**（8.4s→0.06s 就是这么量出来的） |
| 行为对不对 / 修好没有 | `evidence-collector` | **真浏览器冒烟**：接口 200 ≠ 页面能用（曾栽两回） |
| 该发版了 / 生产就绪检查 | `reality-checker`（+`technical-writer`） | 走 `docs/开发纪律.md` 清单 |

**召唤提示词模板**（派子代理 / 自查时照此写，不临场发挥）：

```text
任务：<一句话>
项目：E:\桌面\focuslog（纯本地零依赖；面板=panel_server.py+dashboard.py 单文件；
     分类=category_utils.py；数据=专注记录\*.txt）
约束：零第三方运行时依赖 / 双主题成对 / 不引入联网 / 中文界面 / GBK 控制台安全
验收：tools 检查面板.py 全过 + node --check + 真浏览器冒烟（console 0 error）+ 端到端实测
输出：结论 + 证据（文件:行号），不要贴大段代码
```

## 1. 发版纪律

- **一律用 `python 工具\发版.py`**（不带 `--push` 只做本地；`--push` 才推 GitHub——
  上传必须等用户明确点头）
- 发版前 **CHANGELOG 必须已有本版本条目**（发版.py 会拒绝）
- README 徽章是**动态 shields**（`img.shields.io/github/v/release/...`，跟随最新
  Release 自动变），**永远不要手写版本号**——"readme 版本又没更新"已根治
- Release 说明从 CHANGELOG 本版本段自动取，不再整份 CHANGELOG 灌进去

## 2. 已踩过的坑（改代码前自问一遍）

- 共用路由入口只判命中，404 兜底留在各入口末尾
- 非 async 函数里写 `await` ⇒ 整页 JS 崩；`node --check` 是权威判据
- 定义了的绘图/渲染函数必须挂上 `draw()` 调用链（`drawHourly`/`renderScan` 曾漏挂）
- 分发清单：`分类方案\*.txt` 与 `工具\清理旧版.ps1` 必须进包；更新覆盖白名单
  必须含 `.ps1`；**`category.txt` 永不覆盖**（`.txt` 只对分类方案目录生效）
- `VERSION.txt` 被 PowerShell `Set-Content -Encoding UTF8` 重写会带 BOM
  （读取一律 `utf-8-sig` + 去 `\ufeff`）
- GBK 控制台：`print` 别用 ⚙ 等打不出的字符；stdout/stderr 加 `errors="replace"`
- 采样口径：锁屏/无键鼠/视频长空闲暂停，别在统计侧"猜"掉这些段
- 实测数字进文档前要标日期与数据量（55 天 vs 100 天口径不同）
