============================================================
  焦点监控系统 — 统计规则说明
============================================================
  本文档适用于焦点监控系统分发版本
  更新日期：2026-09-21（v2.7.1）
============================================================

【目录说明】
  焦点监控\      ← 程序代码目录（启动/停止脚本、focus_tracker.py）
  专注记录\     ← 数据目录（日志、统计配置、分类规则、深耕记录）


【采样机制】
  采样间隔：10秒
  每次采样：时间戳 | 进程名 | 窗口标题
  格式： HH:MM:SS|process.exe|窗口标题文字
  日志文件：专注记录\YYYY-MM-DD.txt（按天一个文件）


【鼠标空闲自动暂停】
  规则：鼠标连续 5 分钟不移动 → 自动暂停，缓冲区内记录丢弃
  恢复：鼠标移动后 → 自动恢复记录，写入 [RESUME] 标记
  豁免（视频类）：mplayerc.exe / vlc.exe / 哔哩哔哩 / YouTube 等，看视频时鼠标不动不会暂停
  缓冲：最多保留 30 条（≈5 分钟），鼠标动了刷入文件，触发暂停清空


【锁屏 / 休眠自动暂停】（v2.7 新增）
  规则：检测到锁屏（Win+L）/ UAC 安全桌面 / 切换用户 / 休眠 → 立即停表
  恢复：解锁 / 唤醒后立即恢复计时
  标记：停表写 [LOCK]|锁屏暂停，恢复写 [UNLOCK]|解锁恢复
  原理：OpenInputDesktop 打开输入桌面；打不开即视为锁屏状态
  意义：锁屏时鼠标本就不动，旧方案会白等 5 分钟才暂停 → 那 5 分钟被误算进在线时长


【日志点压缩】（v2.6 新增）
  连续处于同一窗口时，后续采样写 "HH:MM:SS|." 而不是重复整行
  「.」在统计时还原为上一条的进程与标题，时长累加不变
  旧格式（每行完整）与点压缩格式可混排，向前兼容


【补齐式归档】（v2.7.1 新增）
  旧版 --archive 只处理「上个月」那一个月份 → 漏跑几个月就再也补不回来。
  新版改为扫描**所有早于本月的月份**，逐月归档：
    · 一次调用补齐全部遗留月份（如 5/6/7 月一起归档）
    · 本月数据始终保留在根目录（还在用，不归档）
    · 已归档到 归档\YYYY-MM\ 的不会被重复收集 → 重复运行安全
  归档后统计功能不受影响 —— _find_all_log_dates 递归扫描含归档目录


【专注时长统计】
  专注 = 仅 #专注# 分类的采样时间
  在线 = 全部非暂停采样时间
  实时显示：专注记录\专注XhXmin_在线XhXmin.txt（后台自动更新）
  状态保存：focus_state.json（重启后继续累加）
  跨日自动归档旧文件到 深耕记录\ 目录


【里程碑通知】
  专注 1h / 3h / 5h 各触发一次 Windows 弹窗提醒


【时长计算】
  相邻两条记录的时间差（14:00:00→14:00:10 = 10秒）
  间隔超过 60 秒 → 视为中断，记 0 秒（锁屏/空闲段不会被多算）
  [RESUME] / [LOCK] / [UNLOCK] 等 [xxx] 标记行一律跳过不计
  「.」省略行按上一条窗口累加


---+ 配置与分类规则 +-----------------------------------------------------


【分类配置文件】category.txt（专注记录 根目录）

  匹配顺序 = 文件行序，从上到下依次匹配，先命中先生效：

     办公(专注) → 学习(专注) → 视频 → 浏览器 → 游戏 → 通讯 → 系统 → 工具(专注)

  学习/视频在浏览器前面 → 浏览器内的学习网站和视频能精确命中学习/视频分类

  当前分类一览：

  分类   专注   说明
  ─────  ────  ────────────────────────────────────────────
  办公   专注   Code.exe, VS(WPS/Office), Typora
  学习   专注   Anki, 粉笔/华图/中公(网页标题匹配)
  视频   非专注   播放器(mpc/vlc), 哔哩哔哩/YouTube/优酷(标题匹配)
  浏览器   非专注   Chrome/Firefox/Edge（浏览器本身不算专注，靠上方 title 精确判断）
  游戏   非专注   Steam, SlayTheSpire, Borderlands, Apex 等
  通讯   非专注   微信/QQ/TIM/KOOK/Discord
  系统   非专注   资源管理器/CMD/终端/火绒/360压缩等系统工具
  工具   专注   WorkBuddy/CodeBuddy/Snipaste/记事本/Everything
  音乐   非专注   酷狗音乐/网易云音乐


---+ 工具命令汇总 +--------------------------------------------------------


【summary.py — 统计与维护核心脚本】

  用法                       说明
  ─────────────────────────  ──────────────────────────────────
  python summary.py          显示当天分类统计
  python summary.py 日期     显示指定日期的分类统计
  python summary.py --export 导出全部日期的统计到 时长统计\
                             文件名含前 3 大分类及时长（如 2026-07-24_游戏_3h36min_工具_59min_系统_33min.txt）
                             已归档月的数据自动写入 时长统计\归档\YYYY-MM\
  python summary.py --archive 把「本月之前」所有遗留记录按月归档（补齐式）
      扫描全部早于本月的月份，逐月归档 —— 不是只处理上个月。
      漏跑几个月后补跑一次即可全部补齐，重复运行安全（已归档的不会重复处理）。
      · 根目录日志 → 归档\YYYY-MM\
      · 深耕记录   → 深耕记录\归档\YYYY-MM\
      · 时长统计   → 时长统计\归档\YYYY-MM\
  python summary.py --classify 交互式分类助手
      扫描全部日志 → 列出累计 ≥15min 的未分类进程 → 选分类 → 自动合并到 category.txt
      已存在 proc= 规则的进程不再显示
  python summary.py --renew 用当前 #专注# 规则重新计算全部深耕记录
      清空深耕记录\ → 逐日计算专注/在线 + 专注窗口明细（≥5min）
      每次修改 category.txt 的 #专注# 标记后执行一次


【批处理文件一览】

  文件                功能
  ──────────────────  ──────────────────────────────────
  查看当天统计.bat   显示当天分类统计
  导出全部统计.bat   导出全部日期的统计到 时长统计\
  图表导出.bat       生成 HTML 饼图 / 柱状图（8 种时间范围可选）
  应用排行.bat       按周 / 月 / 全部查看应用用时排行
  归档.bat           把本月之前的所有遗留数据按月归档（补齐式）
  分类助手.bat       交互式分类助手（为未分类进程添加规则）
  更新深耕记录.bat   用当前 #专注# 规则重算全部深耕记录

  ├── 时长统计\               分类统计输出
  │   ├── 归档\YYYY-MM\       已归档月份的统计

  │
  ├── 深耕记录\               专注/在线记录

---+ 快速上手（第一次使用） +----------------------------------------------


  1. 双击"启动焦点监控.bat" → 后台开始采样

  2. 双击"导出全部统计.bat" → 生成首次全量统计
     统计文件在 专注记录\时长统计\ 下

  3. 用"分类助手.bat"给未分类进程添加规则
     双击 → 扫描后按编号选分类 → 自动写入 category.txt

  4. 每周/每月跑一次"归档.bat" → 自动归档本月之前的所有遗留数据
     （漏跑也没关系，下次补跑会把落下的月份一起补上）

  5. 修改 category.txt 的 #专注# 标记后 → 跑"更新深耕记录.bat"


---+ 数据生命周期 +--------------------------------------------------------


  1. focus_tracker.py 后台运行 → 实时采样写入 YYYY-MM-DD.txt

  2. 每天零点 → 自动归档昨日专注摘要到 深耕记录\

  3. 运行导出全部统计.bat → 读取全部日志 → 生成分类统计到 时长统计\

  4. 运行归档.bat → 本月之前的日志/深耕/统计按月移入对应归档子目录

  5. 运行分类助手.bat → 分析未分类进程 → 交互式添加规则

  6. 运行更新深耕记录.bat → 用最新 #专注# 规则重新计算全部深耕记录
