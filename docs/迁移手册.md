# 从旧版本迁移数据（操作手册）

> 适用：你以前用的是「桌面上的两个文件夹」那套（`焦点监控\` + `专注记录\`），
> 现在换成了**单目录**的新版（`focuslog\`，里面同样有这两个子目录）。
> 迁移就是**把老日志与分类配置搬进新目录**，老文件夹原样保留。

## 一句话版本

双击 **`迁移旧版本.bat`**（在 focuslog 根目录）→ 看完报告 → 启动监控。

---

## 迁移前

| 检查 | 说明 |
|---|---|
| 旧文件夹在哪 | 默认会自动找「桌面\焦点监控」；也可以手动指定（见下） |
| 监控是否在跑 | 建议先双击旧版本的「停止监控.bat」再迁移，避免两边同时写 |
| 磁盘空间 | 迁移只复制，占用与旧数据差不多（几十年日志也就几十 MB） |

## 迁移的三步

**第 1 步 · 跑迁移**

双击 `迁移旧版本.bat`。它会：

1. 自动找到旧目录（找不到会告诉你怎么手动指定）
2. 把旧数据**整包备份**到 `_migrate_backup_年月日_时分秒\`
3. 复制：每天的日志、`归档\`、`深耕记录\`、`时长统计\`、`category.txt`、`focus_state.json`
4. 校验：打印新目录里现在有多少天日志、累计在线多少小时
5. 把开机自启重新指向新目录的程序

> 旧目录**只读**：全程只复制，不移动、不删除；同名文件一律跳过（绝不覆盖新目录已有内容）。

**第 2 步 · 核对**

双击 `打开面板.bat`，看「全部」范围里的：
- 最早那天是不是你最早的记录
- 累计在线时长是否与旧版统计一致（旧版 `summary.exe` 跑一次对比即可）
- 「分类管理」里规则条数对不对

**第 3 步 · 收尾**

- 双击 `启动监控.bat`（若之前没在跑）
- 双击 `开机自启.bat`（确认自启指向新路径）
- 确认无误后，旧的两个文件夹可以删（不放心就先留着）

## 手动指定旧目录

如果迁移工具没找到，用命令行：

```bat
python 工具\migrate.py --from "D:\某个位置\焦点监控"
python 工具\migrate.py --dry-run          :: 只检查不写文件
```

`--from` 指向**旧的那些程序所在的文件夹**（里面有 `focus_tracker.py` 或 `.exe`），
工具会在它里面 / 它的兄弟目录里找 `专注记录`。

## 常见问题

**Q：新目录里已经有我这几天的数据了，会不会被老数据覆盖？**
不会。同名日志一律跳过，只补缺的那些天。

**Q：分类规则不一样怎么办？**
新目录已有 `category.txt` 时，工具会**保留现在用的**，把旧的另存为
`专注记录\category_来自旧版本.txt`，你可以对照着把差异手工补进去。

**Q：迁移后统计里少了几天？**
先看 `_migrate_backup_*\` 备份是否完整；缺的天大概率是旧目录里本来就没有
（比如那天没开机）。可用 `python tests\selftest.py` 确认解析器没问题。

**Q：旧的 exe 还在跑，会不会双份记录？**
会。迁移前先停掉旧版监控（旧目录的「停止监控.bat」），迁移后只用新目录的入口。
新版有文件锁，同一目录不会被重复启动。

**Q：能回退吗？**
能。旧目录没被动过；新写入的数据也都在新目录里，把新目录的 `专注记录\` 换成
备份目录里的那份即可（先在监控停止状态下操作）。
